# Archive — the ComfyUI era (2026-08-26 to 2026-08-29)

Everything in this folder describes the first version of this server: a local ComfyUI install
with FLUX models, pinned workflow graphs, and a trained house-style LoRA. **None of it exists
anymore.** ComfyUI, the checkpoints, ai-toolkit, the training runs, and the corpus were deleted
from the machine on 2026-09-19 when the project moved to the Gemini image API.

Kept for history only: why the LoRA was judged a win at the time and why it was not one in
practice, what the local loop cost per image, and the phrasing lessons that were specific to
FLUX. Do not treat any path, model name, tool mode, or workflow in these files as current. The
live plan is [../../ROADMAP.md](../../ROADMAP.md).
